Instalação rápida (recomendado)

1
Instale a extensão base Ex.: Tampermonkey (Chrome/Firefox/Edge) e quaisquer dependências.
2
Baixe os scripts necessários Baixe os arquivos .user.js na seção “Scripts”.
3
Importe e ative Abra o arquivo e confirme “Install”. Verifique se está “Enabled”.
4
Teste com um exemplo Use o botão “Demos” para ver prints/vídeos e validar.

FAQ

O script não apareceu. O que eu checo primeiro?

1) Se a extensão está habilitada. 2) Se o script está “Enabled”. 3) Se o site está no @match. 4) Se você está no navegador certo (Chrome/Firefox) e logado.

Como atualizo para a versão mais nova?

Baixe a versão nova do script e reinstale por cima, ou use o botão “Update” na extensão (se você publicar um link de update).

Posso ter conflitos entre scripts?

Pode. Evite scripts duplicados para a mesma página. Se der problema, desabilite um por vez e teste.
